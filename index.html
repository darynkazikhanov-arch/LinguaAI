⚡ AI Algorithms & Search Lab

Interactive implementations of the four core AI algorithms built into LinguaAI for adaptive learning, text classification, and graph traversal.

1. Decision Tree — Adaptive Recommendation Engine

Simulate student metrics to observe real-time decision-tree branching and rule evaluation.

2. Naive Bayes Classifier — Mathematical Formula & Laplace Smoothing

Calculates posterior probabilities using Bayes' Theorem with Laplace add-one smoothing:

P(C|W) = P(C) * ∏ P(w_i | C) / P(W)   |   P(w|C) = (count(w,C) + 1) / (totalWords(C) + |V|)

3. Breadth-First Search (BFS) — Shortest Learning Path

Finds the minimum number of topic transitions between any two English learning concepts using a Queue.

4. Depth-First Search (DFS) — Deep Topic Explorer

Explores subtopics deeply along single curriculum branches before backtracking using recursion/stack.
